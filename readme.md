# **Order of Operations**

## **Your First Answer**

What is `2+3⋅4`?

Ask ten people and you get two answers: 20 and 14. Both groups are sure. Only one answer is right.

The rule: multiply before you add, so `2+3⋅4=14`.

(The dot means times.)

## **Left to Right**
A classic slip: working out `15−6+3` as 6. That adds `6+3` first and then takes 9 away. But only the 6 is taken away. The 3 is added.

Plus and minus are equal, so neither one goes first. **Work from left to right.** `15−6` is 9. Then `9+3` is 12.
